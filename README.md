# 방통대 문제은행 (knou-quiz)

한국방송통신대학교 시험 대비 문제은행 웹앱입니다. 한 링크에서 과목을 골라 풀 수 있습니다.

🔗 **https://onione2173.github.io/knou-quiz/**

## 과목

| 과목 | 기출 | 강의록 예상문제 | 합계 |
|---|---|---|---|
| 🌱 생활원예 | 250문항 (2015~2019년 2학기 기말·출석대체 10회) | 300문항 (01~15강, 강당 20문항) | 550문항 |
| 📖 인간과교육 | 600문항 (2015~2019년 2학기 기말·하계계절 16회) | 300문항 (01~15강, 강당 20문항) | 900문항 |

- 홈 상단 **과목 선택**에서 `🌱 생활원예` / `📖 인간과교육`을 눌러 전환합니다.
- 두 과목 모두 같은 기능을 씁니다: 3가지 출제 구성(기출+강의록 20% 혼합 · 기출만 · 강의록만), 전체 문제 무작위 출제, 선지 순서 섞기(해설 번호 자동 치환), 🙈 24시간 안 보기, 오답노트·북마크·학습 기록.

## 자료 출처와 검증

- 기출: U-KNOU 캠퍼스(ucampus.knou.ac.kr) 해당 과목 강의자료실의 기출문제와 정답표를 내려받아 문항·선지를 전수 추출하고 정답표와 1:1 대조했습니다.
- 인간과교육 2019학년도 2학기 기말 2부(1학년 3교시 1~35번·3학년 2교시 36~70번)는 PDF에 텍스트가 없어 이미지에서 문항을 옮겨 적고 정답표로 검증했습니다.
- 인간과교육 2015학년도 3학년 미주지역 시험은 서술형이라 문제은행에서 제외했습니다.
- 같은 문항이 여러 회차에 반복되는 경우 `중복 문항 제외` 옵션으로 한 번만 풀 수 있습니다(인간과교육은 600문항 중 301건이 반복 문항).
- 강의록 예상문제는 각 강의록 본문에서 다룬 개념만으로 출제했고, 기출 문항과 겹치는 문항은 없습니다.

## 저장 방식

- 오답노트·북마크·학습 기록·24시간 숨김은 **과목별로 따로** 저장됩니다(예: `hw_wrong_v1_horti`, `hw_wrong_v1_edu`).
- 마지막으로 고른 과목, 학습 모드, 출제 구성, 선지 섞기 설정은 두 과목이 공유합니다.
