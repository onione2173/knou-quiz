# 방통대 기출문제 은행

한국방송통신대학교 기출문제를 모아 푸는 웹 앱입니다. 설치 없이 브라우저에서 바로 열립니다.

## 수록 범위

- **생활원예** — 250문항
  - 2015·2016·2017·2018·2019학년도 2학기 기말 (각 35문항)
  - 2015·2016·2017·2018·2019학년도 2학기 출석수업대체 (각 15문항)

## 기능

- 연도·시험 종류별 세트 선택, 순차 풀이 / 즉시 채점
- 문제별 정답·해설 보기, 오답 다시 풀기
- 북마크(별표), 학습 통계, 다크 모드
- 학습 상태는 브라우저 로컬 저장소에만 저장됩니다 (서버 전송 없음)

## 구조

```
index.html   # 앱 전체 (문항 데이터 포함, 단일 파일)
data/        # (예정) 과목별 문항 JSON — 2차 3과목 추가용
```

## 갱신 방법

`index.html`을 새 버전으로 바꿔 커밋하면 GitHub Pages가 자동으로 다시 배포합니다.
