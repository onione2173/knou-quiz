# 방통대 문제은행

한국방송통신대학교 기출문제와 강의록 기반 예상문제를 모아 푸는 웹 앱입니다. 설치 없이 브라우저에서 바로 열립니다.

## 수록 범위

- **생활원예 기출 — 250문항**
  - 2015·2016·2017·2018·2019학년도 2학기 기말 (각 35문항)
  - 2015·2016·2017·2018·2019학년도 2학기 출석수업대체 (각 15문항)
- **생활원예 강의록 예상문제 — 300문항**
  - U-KNOU 캠퍼스 생활원예 강의자료실 01~15강 강의록을 근거로 출제
  - 단원(강)마다 20문항, 15개 단원 × 20문항

## 기능

- **출제 구성 3가지**
  1. **기출+강의록(기본)** — 한 회차 문항의 20%를 강의록 문제로 채우고 나머지를 기출에서 뽑아 섞습니다. (예: 35문제 = 기출 28 + 강의록 7, 전체 풀이 = 기출 250 + 강의록 63)
  2. **기출만** — 연도·시험 종류별 세트 선택
  3. **강의록만** — 01~15강 단원별 선택
- 강의록 문제에는 문제·결과·오답노트·북마크 화면에 `강의록` 배지가 붙습니다
- **매번 완전 무작위 출제** — 선택한 범위의 전체 문항(기출 250·강의록 300)을 매 시작마다 섞어서 뽑습니다. '기출+강의록'도 기출·강의록을 각각 섞은 뒤 20% 비율로 맞추고 최종 순서까지 섞으며, 범위와 문제 수 기본값은 '전체'입니다.
- **🙈 24시간 안 보기** — 잘 아는 문제는 문제 화면에서 버튼 한 번으로 24시간 동안 출제 풀에서 빠집니다(같은 버튼으로 바로 해제). 홈의 '24시간 안 보기 N문제'에서 목록 확인·개별 해제·전체 해제가 되고, 숨긴 문제 때문에 풀 문제가 0개가 되면 안내와 함께 '숨김 초기화하고 풀기'를 제공합니다
- 시작할 때마다 선지 1~4번 순서를 섞어 같은 문제도 매번 다른 배치로 출제
- 즉시 채점 / 실전 모의고사, 문제별 정답·해설, 오답 다시 풀기
- 북마크(별표), 학습 통계, 다크 모드
- 학습 상태는 브라우저 로컬 저장소에만 저장됩니다 (서버 전송 없음)
